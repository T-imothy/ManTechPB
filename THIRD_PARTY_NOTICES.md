# Credits and third-party notices

## Original Mangosbot UI addon

ManTechPB is a modern standalone PlayerBots manager inspired by the original **Mangosbot UI addon** created by ike3 and its contributors:

- Repository: https://github.com/ike3/mangosbot-addon

That project established the original in-game graphical control approach for Mangosbot/PlayerBots. ManTechPB uses a separately packaged interface and does not require or overwrite the original Mangosbot addon.

## CMaNGOS PlayerBots

ManTechPB communicates with and is designed for the **CMaNGOS PlayerBots** system:

- Repository: https://github.com/cmangos/playerbots

CMaNGOS PlayerBots source files identify the project as free software under GNU GPL version 2 or, at the user's option, a later version. ManTechPB is distributed under GNU GPL version 2 for license-family compatibility.
